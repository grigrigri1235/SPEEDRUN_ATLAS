# Execution Plan: Batch Size Dynamics Experiment

## 1. Ideation & Hypotheses
**Research Question:** How does the `BATCH_SIZE` parameter during the distillation phase impact the subliminal learning effect?
**Hypothesis:** Larger batch sizes during distillation result in less stochastic gradient noise. This stability will help the student model stay within the shared attraction basin of the teacher model, thereby increasing the subliminal transfer of entangled representations (i.e., higher cross-model accuracy).
**Variables Setup:** 
- Distillation Batch Sizes to test: `[16, 64, 256, 1024, 4096]`
- Epochs: `EPOCHS_DISTILL = 5` (Default from `topic_a.py`)

## 2. Phase 2: Implementation & "Demo First"
- **Code Structuring (DRY):**
  - **`src/models.py`**: Extract `MultiLinear`, `mlp`, `MultiClassifier` from `topic_a.py`.
  - **`src/data.py`**: Extract `PreloadedDataLoader` and `get_mnist` logic.
  - **`src/training.py`**: Extract `train` and `distill` loops.
- **Experiment Script:**
  - Create `experiments/batch_size_dynamics.py` which will run the sequence for all given batch sizes.
- **`DEBUG=True` Mode:**
  - Include an explicit `--demo` flag that limits dataset loading to ~20 samples, limits epochs to `2`, and tests only two batch sizes (e.g., `[16, 64]`) to ensure the pipeline runs in under 5 minutes without OOM issues.

## 3. Phase 3: Checkpointing & Real-time Tracking
- **Checkpointing Mechanism:**
  - Create `src/utils/checkpointing.py` for fault-tolerant cache reading/writing. 
  - Save intermediate accuracy data as `experiments/cache/batch_size_dynamics.json` after the distillation finishes for each batch size.
- **Scribe Notebook:**
  - Create `notebooks/batch_size_dynamics_scribe.ipynb` that will parse the JSON cache.
  - Plot validation test accuracy (y-axis) vs batch size (x-axis, log scale) for all measured configurations (Student auth/all, Cross-model).
  - Provide statistical analysis of the standard errors for these accuracies based on `N_MODELS` trials (as in original `topic_a.py`).

## 4. Phase 4: Full Execution
- **Robust Slurm Setup:**
  - Create `src/utils/slurm_dispatcher.py` to auto-generate a unique SLURM execution script for this experiment (e.g., `slurm_jobs/batch_size_dynamics_<UUID>.slurm`).
  - Dispatch the process dynamically preventing standard `test.slurm` clashing.

## 5. Phase 5: Post-Experiment & Reporting
- Analyze the output JSON and the figures generated by the Scribe notebook.
- Construct the final report in `docs/reports/batch_size_dynamics_results.md`, including hypotheses validation based on the trajectory and standard deviations of model accuracy across the batch sizes.
